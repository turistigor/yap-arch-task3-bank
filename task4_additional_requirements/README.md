# Задание 4. Передача ставок в кол-центр

Предлагаемое решение передачи информации о ставках депозитов в формате [ADR](deposit_rates_to_call_centers_adr.md).

[Список](tasks_list.md) крупных задач и road map ([drawio](road_map.drawio) | [png](road_map.png)) для реализации передачи информации о ставка депозитов в банковскую и партнерскую системы кол-центра. 

Задание было выполнено исходя из предположения о том, что был реализован основной вариант из ADR для MVP онлайн депозитов, подразумевающий наличие отдельного сервиса депозитов. Все текущие документы являются дополнительными к тем, которые были созданы в задаче 3 (MVP онлайн депозитов).
